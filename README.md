# Интеграции 1С — учебный стенд

Тренажёр для отработки **Блока 1 — «Интеграции и обмены»**, самого
востребованного типа доработок 1С. Первый сценарий: загрузка банковской
выписки в 1С.

## Зачем мок банка

Реального доступа к API Halyk или Jusan нет и не будет, пока нет договора
с банком. Мок отдаёт выписку по HTTP ровно так же, как это делает боевой API —
обработка в 1С, написанная против мока, потом работает с настоящим банком.
Меняется только адрес и авторизация.

## Запуск

```bash
pip install flask
python integrations_1c/mock_bank/bank_server.py
```

Открыть [http://127.0.0.1:8080](http://127.0.0.1:8080) — там справка и ссылки на методы.

| Метод | Что отдаёт |
|---|---|
| `GET /api/v1/statement?date_from=&date_to=` | Выписка за период |
| `GET /api/v1/balance` | Остаток на счёте |

## Выписка «грязная» — это специально

Настоящие банковские выписки именно такие. Вся ценность интеграции — в умении
их разобрать, поэтому в мок заложены типовые проблемы:

| Что подмешано | Чему учит |
|---|---|
| БИН в назначении пишется по-разному: `БИН 123…`, `б/н123…`, `бин: 123…` | Разбор регулярным выражением |
| Часть плательщиков отсутствует в справочнике 1С | Обработка не должна падать, платёж уходит в «не сопоставленные» |
| Платёж `000000123` приходит **дважды** | Идемпотентность — без неё в 1С появится задвоенное поступление |
| «ТОО Астана Строй» и «ТОО Астана-Строй» — разные БИН | Сопоставлять можно только по БИН, не по названию |
| Сервер в 20% случаев отвечает 500 или зависает | `Попытка…Исключение` и ретраи |

Чтобы спокойно отладить основную логику, можно временно выставить
`ВЕРОЯТНОСТЬ_СБОЯ = 0` в `bank_server.py`.

## Ключевые принципы, которые отрабатываем

**Запрос в цикле — табу.** Наивно: на каждый платёж делать запрос «найди
контрагента по БИН». 200 платежей = 200 запросов = база на коленях.
Правильно: собрать все БИН в массив, сделать **один** запрос
с условием `В (&МассивБИН)`, дальше работать с результатом в памяти.

**Идемпотентность.** Регистр сведений с ключом «банк + номер документа + дата».
Повторная загрузка не создаёт дублей. Без этого бухгалтер один раз нажмёт
кнопку дважды и получит задвоенные поступления.

**Расширение, а не правка конфигурации.** Всё складываем в расширение,
чтобы обновление типовой Бухгалтерии не снесло доработку.

## Окружение

1С:Предприятие 8.3, учебная версия (бесплатная) на Windows.
Ограничения учебной версии — 2000 записей в таблицах, только файловый режим —
для стенда несущественны.

Мок банка и 1С запускаются на одной машине и общаются через `localhost`.
